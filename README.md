# فاتورة سريعة (Quick Invoice) 📱🧾

تطبيق أندرويد متكامل لإدارة الفواتير، ونقاط البيع السريعة، ودليل السلع والمنتجات.
تم تطويره باستخدام **Kotlin** و **Jetpack Compose** و **Room Database** وفق معايير Material Design 3 مع دعم كامل للغة العربية (RTL).

---

## 🌟 الميزات الرئيسية

1. **دليل السلع والمنتجات (Products Catalog)**:
   - إضافة سلع جديدة مع تحديد الاسم والسعر الافتراضي.
   - تعديل أو حذف أي سلعة مع تأكيد الحذف.
   - بحث فوري وسلس في السلع مع عداد إجمالي.

2. **إكمال تلقائي فوري وسلس (Autocomplete)**:
   - اقتراحات فورية بمجرد كتابة أول حرف من اسم السلعة داخل الفاتورة أو الوضع السريع.
   - تعبئة الاسم والسعر تلقائياً مع نقل المؤشر مباشرة لحقل الكمية دون الحاجة لإعادة الكتابة.
   - إمكانية حفظ السلع الجديدة تلقائياً في الدليل للفواتير القادمة.

3. **الوضع السريع (Quick Calc)**:
   - واجهة حساب فوري لعمليات البيع السريعة.
   - آلة حاسبة مدمجة مع زر نقل الناتج مباشرة للسعر (`→`).
   - شرائح السلع الشائعة، وشرائح الخصم والضريبة السريعة.
   - تراجع فوري عن آخر صنف.

4. **فاتورة كاملة واحترافية (Full Invoice)**:
   - تخصيص اسم العميل، رقم الفاتورة، التاريخ، والخصم، والضريبة %.
   - تحديد حالة الدفع (مدفوعة / غير مدفوعة).
   - جدول الأصناف مع احتساب المجاميع بدقة.

5. **الفواتير المحفوظة (Saved Invoices)**:
   - تبويبان: الفواتير النشطة وسلة المحذوفات.
   - إمكانية استعادة الفواتير المحذوفة أو الحذف النهائي.
   - فلاتر وبحث بالعميل ورقم الفاتورة وحالة الدفع.
   - نسخ الفاتورة أو طباعتها ومشاركتها كنص أو عبر الطابعة.

6. **الإعدادات والنسخ الاحتياطي (Settings)**:
   - تخصيص اسم المتجر، الهاتف، العنوان، ورمز العملة (د.ج).
   - خيارات المظهر: فاتح / داكن / النظام.
   - تصدير واستيراد النسخ الاحتياطية بصيغة JSON.
